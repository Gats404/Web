============================================================
  Behoof — интернет-магазин электроники (ЛР 5-9)
  Инструкция по запуску
============================================================

ТРЕБУЕТСЯ: PHP 7.4+ и MySQL (проще всего — OpenServer или XAMPP).

--------------------------------------------------
1. БАЗА ДАННЫХ (для каталога)
--------------------------------------------------
- Запустите MySQL.
- Откройте phpMyAdmin (http://localhost/phpmyadmin) ->
  вкладка «Импорт» -> выберите файл shop_db.sql -> «Вперёд».
  (или из консоли: mysql -u root -p < shop_db.sql)
- Создастся база shop_db и таблица products с 8 товарами.

Если MySQL работает на нестандартном порту (в OpenServer часто 3307),
впишите его в catalog_logic.php:
    $host = '127.0.0.1:3307';

--------------------------------------------------
2. ЗАПУСК САЙТА
--------------------------------------------------
- Скопируйте папку lab5-9 в корень веб-сервера
  (OpenServer: C:\OSPanel\domains\... ; XAMPP: htdocs\...).
- Откройте в браузере: http://localhost/lab5-9/index.php

--------------------------------------------------
3. ОТПРАВКА ПОЧТЫ (форма поддержки и подписка)
--------------------------------------------------
Работают через PHPMailer + Gmail SMTP. Чтобы письма реально уходили:
- В send_mail.php и subscribe.php заполните:
      $mail->Username = 'ваш_адрес@gmail.com';
      $mail->Password = 'пароль_приложения';   // 16 символов
- «Пароль приложения» создаётся в аккаунте Google:
  Безопасность -> Двухэтапная аутентификация -> Пароли приложений.
- Библиотека PHPMailer уже лежит в папке PHPMailer/src (composer не нужен).

Без заполнения SMTP формы вернут ошибку отправки — это нормально,
вёрстка и AJAX при этом работают.

--------------------------------------------------
4. ОТЗЫВЫ
--------------------------------------------------
Хранятся в файле reviews.txt (JSON). БД для них не нужна.
Папка должна быть доступна на запись.
