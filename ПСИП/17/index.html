    Схема классов

    Наследование — сплошные стрелки, использование — пунктир. # — приватное, _ — защищённое, static — статическое.

    Product
    • static #created
    • #price, #discount
    • _category
    • id, name, brand, rating, inStock
    • get/set price, discount
    • get finalPrice
    • getInfo(), badges(), render()
    • static fromJSON(), format(), compareByPrice()
    extends ▲extends ▲
    Smartphone
    • screen, storage, camera, has5G
    • getInfo() ⟲
    • badges() ⟲ super
    Speaker
    • assistant, power, smartHome
    • getInfo() ⟲
    • badges() ⟲ super
    Catalog
    • #products: Product[]
    • get all, get size
    • getById(), query()
    • static fromJSON(), async load()
    uses ⇢ Product
    Cart
    • #items: Map, #listeners
    • add(), setQty(), remove(), clear()
    • get items, count, total
    • onChange(), #emit()
    • static fromJSON()
    uses ⇢ Cart
    Order
    • static #lastNumber
    • number, date, customer, lines, total
    • get summary
