    События на этой странице

    Все сценарии пишут в журнал событий (кнопка внизу слева).

    1. Мышьclick — «В корзину»; dblclick — увеличение фото; mouseenter/mouseleave — подсветка карточки; mousemove — свет за курсором в баннере; contextmenu — своё меню.
    2. Клавиатураkeydown «/» — фокус в поиск; input — подсказки; ↑ ↓ — выбор подсказки; Enter — открыть; Esc — закрыть окна.
    3. Drag & Dropdragstart → dragenter → dragover → drop → dragend: перенос карточки в корзину или избранное.
    4. Указательpointerdown / pointermove / pointerup + setPointerCapture — ползунок «Цена до» (мышь, палец, перо).
    5. Прокруткаscroll — прогресс-бар, компактная шапка, кнопка «Наверх», автоподгрузка товаров, запуск счётчиков.
    6. Сенсорный экранtouchstart / touchmove / touchend — свайп промо-слайдера пальцем.
    7. ТаймерыsetInterval — обратный отсчёт акции и автосмена слайдов; setTimeout — печатная машинка, исчезающие уведомления.
