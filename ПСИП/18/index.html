Задание 2. Валидация формы регистрации тремя способами

Способ 1Атрибуты HTML5

required, minlength, maxlength, pattern, type="email", type="url", min/max. Проверяет сам браузер, стили — :invalid.

Способ 2Проверки на JavaScript

Атрибут novalidate отключает браузерную проверку: всё проверяет скрипт — пустые поля, длина, формат, совпадение паролей, диапазон чисел.

Способ 3Регулярные выражения

Каждое поле проверяется своим шаблоном RegExp прямо при вводе (событие input).

  • не короче 8 символов /.{8,}/
  • строчная буква /[a-zа-яё]/
  • заглавная буква /[A-ZА-ЯЁ]/
  • цифра /\d/
  • спецсимвол /[^\w\s]/
