Объектная модель браузера (BOM)

Глобальный объект window — это само окно браузера. Через него доступны остальные объекты BOM: адрес страницы, сведения о браузере, история переходов и параметры экрана.

Объект window

Окно браузера: открытие и закрытие окон, таймеры, размеры, диалоговые окна.

Пример 1Межоконное взаимодействие

Главное окно открывает окно оформления заказа, передаёт ему данные через postMessage и получает ответ обратно через window.opener.

Пример 3Управление окном и таймеры

setInterval считает время на странице, setTimeout показывает уведомление об акции, кнопки переходят на сайт и обновляют страницу.

Доп. примерРазмеры окна и диалоги

Свойства окна обновляются по событиям resize и scroll. Методы alert, confirm, prompt — тоже методы window.

Объект location

Адрес текущей страницы: чтение частей URL, GET-параметры, переходы.

Доп. примерРазбор адреса страницы

Таблица перестраивается при смене location.hash (событие hashchange).

Пример 7Каталог с параметрами поиска

Как фильтры интернет-магазина: параметры попадают в URL (?category=…&maxPrice=…), а страница каталога читает их через location.search и URLSearchParams.

Доп. примерМетоды навигации

assign() добавляет запись в историю, replace() — заменяет текущую (кнопка «Назад» сюда уже не вернёт), reload() перезагружает страницу.

Объект navigator

Сведения о браузере и системе пользователя, состояние сети, системные API.

Пример 2Информация о браузере и системе

Заполняется при загрузке страницы (событие DOMContentLoaded).

Доп. примерОнлайн или офлайн

navigator.onLine + события online/offline. Отключите сеть в DevTools (Network → Offline), чтобы увидеть смену статуса.

Объект history

История переходов текущей вкладки: назад, вперёд и состояния одной страницы.

Доп. примерПереходы по истории

history.length — сколько записей в истории вкладки. Методы back(), forward(), go(n) работают как кнопки браузера.

Объект screen

Параметры монитора пользователя — для аналитики и адаптации интерфейса.

Пример 5Дашборд характеристик экрана

screen.width × height (полоса снизу — панель задач) availWidth × availHeight окно браузера (outerWidth × outerHeight, screenX/Y)

Пример 6Тип устройства (screen + navigator)

Ширина экрана + userAgent + число точек касания. Пересчитывается при изменении размера окна.

    Доп. примерПодстройка магазина под экран

    По screen.width × devicePixelRatio выбирается размер баннера, по availWidth — число колонок каталога.
